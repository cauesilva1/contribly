# i18n (PT / EN)

Stack: **next-intl**

## URLs

- Português (padrão): `/`, `/auth`, …
- English: `/en`, `/en/auth`, …

Seletor **PT | EN** no header.

## Arquivos

- `messages/pt.json` / `messages/en.json` — textos
- `src/i18n/routing.ts` — locales
- `src/i18n/navigation.ts` — `Link` / `redirect` / `useRouter` com locale
- `src/app/[locale]/…` — páginas

## Como traduzir mais páginas

1. Adicione chaves em `messages/pt.json` e `messages/en.json`
2. Server Component: `const t = await getTranslations('namespace')`
3. Client Component: `const t = useTranslations('namespace')`
4. Links internos: `import { Link } from '@/i18n/navigation'` (não `next/link`)
