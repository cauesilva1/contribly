# i18n

Stack: **next-intl**

## Current mode: English only

- Default / only active locale: **`en`**
- UI strings: `messages/en.json`
- Portuguese archive: `messages/pt.json` (kept for later; not loaded)
- Language switcher: commented out in `site-header-client.tsx`
- Legacy `/pt` and `/pt/...` redirect to the English unprefixed path

## URLs

- English: `/`, `/auth`, `/discover`, …

## Re-enable Portuguese later

1. In `src/i18n/routing.ts`, uncomment `"pt"` in `locales` (optionally change `defaultLocale`)
2. Uncomment `<LocaleSwitcher />` in `src/components/site-header-client.tsx`
3. Restore `lang` / Open Graph locale branching in `src/app/[locale]/layout.tsx` if desired
4. Keep editing both `messages/en.json` and `messages/pt.json` when adding copy

## How to use translations

1. Add keys to `messages/en.json` (and `pt.json` when PT is back)
2. Server: `const t = await getTranslations('namespace')`
3. Client: `const t = useTranslations('namespace')`
4. Links: `import { Link } from '@/i18n/navigation'`
