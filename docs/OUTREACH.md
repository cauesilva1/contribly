## LinkedIn (post)

```
I just launched Contribly 🚀

It's open-source matchmaking: find projects to contribute to, swipe interest, and let maintainers accept / invite — all with GitHub login.

The problem I wanted to solve:
• finding a real “good first issue”
• knowing whether a project actually wants help
• taking the next step without getting lost in silence

What ships today:
→ profile & skills synced from GitHub
→ discover / recommendations / swipe
→ maintainer dashboard + inbox
→ issue sync (good first / help wanted)

If you contribute to or maintain OSS, try it and tell me what’s missing:
https://contribly.vercel.app

Feedback (and PRs) welcome 🙌
https://github.com/cauesilva1/contribly

#OpenSource #GitHub #Developers #Contribly #BuildInPublic
```

## Quick tips

1. On LinkedIn, a screenshot of the home or swipe screen usually gets more replies.
2. On Discord, check server rules — many ask for `#showcase` / `#self-promo`.
3. Don’t paste the same message into 20 channels at once; personalize one line (“saw you talk about first contributions…”).
